# Mustafa Aboalazm OS
Personal Design Operating System — Next.js 15 · TypeScript · Tailwind v4 · Framer Motion · GSAP · Lenis · MDX · Sanity.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Push to GitHub → import on Vercel → add env vars from `.env.example` → Deploy.
Site runs fully on seed data until Sanity env vars are set.
