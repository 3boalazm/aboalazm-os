# Mustafa Aboalazm OS
Personal Design Operating System — Next.js 15 · TypeScript · Tailwind v4 · Framer Motion · GSAP · Lenis · MDX · Payload CMS (Postgres/Neon).

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Push to GitHub → import on Vercel → add `DATABASE_URI` and `PAYLOAD_SECRET` from `.env.example` → Deploy.
See `RUN_LOCALLY.md` for the full migration/seed steps and known gotchas.
