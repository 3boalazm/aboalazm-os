# Home Preview — Dark Editorial Systems

## Direction
A systems-led editorial direction: quiet dark canvases, expressive typography, art-directed portfolio imagery, asymmetrical project layouts, and a restrained role-based color language. Orange remains the signature action color; supporting hues carry distinct information roles.

## Usage rules
- No light section backgrounds; page, panel, raised and lift are all dark.
- Orange is reserved for primary actions, active emphasis and a small number of anchors.
- Use one supporting color family per discipline: mint for brand, cyan for digital, lavender for business systems, rose for healthcare proof.
- Supporting hues are navigation cues, not the only carriers of meaning. Long-form copy remains neutral.
- Homepage narrative is limited to six main movements; detailed proof and service depth remain on dedicated routes.
