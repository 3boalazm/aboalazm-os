جزء 05 — المحتوى

إزاي أكتب بوست؟

أكتر سؤال تعبكم — 3 formulas تغطي أغلب الحالات

Project Post

عملت إيه ← التحدي ← اتعلمت إيه ← صورة

Learning Post

"خلّصت كورس / قريت عن X — دي أهم 3 حاجات اتعلمتها"

Event Post

حضرت إيه ← أهم Takeaway ← Tag للمتحدث أو المنظم

البوست مش لازم يكون إنجاز كبير. المهم الاستمرارية: بوست كل أسبوعين كفاية كبداية. الـ 3 formulas دول يغطوا أغلب الحالات اللي الطالب ممكن يواجهها.

المحتوى · مثال

مثال بوست كامل

Student · Architecture

PROJECT POST

Just wrapped up my 3rd-year design studio project: a community library for [area].

The hardest part? Balancing natural light with heat control.

What I learned: start with the climate, not the form.

Looking back at my 1st-year work, I can see how much my process has changed.

Would love feedback from architects in the field 👇

#Architecture #StudentWork

لاحظ إنه بيوري التطور ويطلب feedback — مش بيدّعي إنه محترف. المصداقية دي هي اللي بتبني الثقة مع الـ Network.
